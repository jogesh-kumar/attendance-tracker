# Attendance Tracker
A simple desktop application built using Python and Tkinter to manage student attendance.

## Features
- Add/Delete subjects
- Mark attendance (Present/Absent)
- Automatic percentage calculation
- 75% warning alert

## Tech Stack
- Python
- Tkinter
- JSON

## How to Run
1. Clone the repository
2. Run: python main.py
