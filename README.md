# 📊 Attendance Tracker

A simple desktop application built using Python and Tkinter to manage student attendance efficiently.

---

## 🚀 Features
- ➕ Add and delete subjects
- ✅ Mark attendance (Present / Absent)
- 📈 Automatic attendance percentage calculation
- ⚠️ 75% attendance warning alert
- 💾 Data stored using JSON

---

## 🛠️ Tech Stack
- Python 🐍
- Tkinter (GUI)
- JSON (Data Storage)

---

## ▶️ How to Run
1. Clone the repository:
   git clone https://github.com/jogesh-kumar/attendance-tracker

2. Navigate to the folder:
   cd attendance-tracker

3. Run the program:
   python main.py
